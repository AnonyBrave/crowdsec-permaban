App behaviour

The web edition has no tray and no Run-key startup: start it with node server.js (a scheduled task works fine). In a container, set the webhook at first launch with PERMABAN_WEBHOOK_URL.

Imported blocklist

The app bans what the list owns and unbans it when it leaves for the configured window. Bans already issued by someone else are never adopted, so leaving the list never unbans them. First run: seed with PERMABAN_BLOCKLIST_URL, _ENABLED, _REFRESH_MINUTES, _UNBAN_MINUTES, _CAP_PER_CYCLE.

Data folder

PERMABAN_DATA_DIR overrides it (dev/test hook). A launch that cannot write the folder opens the history read-only — bans are issued, records stay frozen.
